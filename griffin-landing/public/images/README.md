# 이미지 자산 관리 지침

이 폴더에는 슬라이더 카드에 사용되는 원본 이미지 **총 18개**(공실관리 3종 + 신축개발 3종 + 자산관리 3종을
각 2회씩 재사용)를 아래 파일명 그대로 넣어주세요.

## 필요한 파일 목록

| 트랙 | 파일명 |
|---|---|
| 공실 해소 (GRIFFIN) | `공실관리1.png`, `공실관리2.png`, `공실관리3.png` |
| 개발(VC) | `신축개발1.png`, `신축개발2.png`, `신축개발3.png` |
| PM/FM(자산관리) | `자산관리1.png`, `자산관리2.png`, `자산관리3.png` |

`index.html`에서는 각 트랙당 3장의 이미지를 2회 반복 참조하여 6장짜리 슬라이더를 구성합니다
(예: `공실관리1→2→3→1→2→3`). 실제 사진이 6장씩 준비되면 `index.html`의 `<img src="...">` 경로만
교체하면 됩니다.

## 경로 규칙 (중요)

- 이 프로젝트는 **Vite**의 `publicDir` 컨벤션을 사용합니다.
- `public/images/파일명.png`에 넣은 파일은 빌드/개발 서버에서 자동으로 **`/images/파일명.png`** 경로로 노출됩니다.
- 따라서 `index.html`의 `<img src="/images/공실관리1.png">` 코드를 수정할 필요 없이, 이 폴더에 실제 파일만
  넣으면 바로 연결됩니다.
- CDN을 사용하려는 경우, `index.html`의 `src` 속성만 CDN 절대경로(예:
  `https://cdn.yourdomain.com/images/공실관리1.png`)로 일괄 치환하면 됩니다.

## 이미지 최적화 권장 사항

- 카드 너비가 320px(모바일은 화면의 84%)이므로 원본은 **최소 960px 폭(3배수)** 이상으로 준비하고
  WebP 변환을 권장합니다.
- `.bs-card img`는 `height:auto`로 종횡비를 유지하도록 되어 있으므로, 트랙별로 이미지의 가로:세로
  비율을 통일해야 슬라이더 카드 높이가 들쭉날쭉해지지 않습니다. (권장: 4:3 또는 3:4 통일)
- `object-fit`을 임의로 추가하지 마세요. 현재는 원본 비율을 그대로 보여주는 것이 의도된 디자인입니다.
